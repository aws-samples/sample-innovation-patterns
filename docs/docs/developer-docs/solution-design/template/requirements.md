# Requirements

> Status: 🔬 Exploring · 📝 Drafting · ✅ Stable — (mark the current one)
> Last updated: 2026-06-25

This is a living document. When the requirements stabilize, the canonical version graduates to `developer-docs/`, `guides/`, or `user-docs/`.

This is the *what*. Pick the flavor that fits the engagement — do not write all three:

- **Business (BRD)** — the business outcome the solution must produce.
- **Product (PRD)** — what the product does for its users.
- **Software (SRS / FRD / TRD)** — what it must do exactly, and under what constraints.

For a POC, a short product-flavored list of capabilities and constraints is usually enough. Add detail only where ambiguity would cost time.
